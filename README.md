# YaMDb — API отзывов на произведения

Учебный командный проект. Сервис собирает отзывы пользователей на произведения (книги, фильмы, музыку), формирует рейтинги и поддерживает комментарии. API на Django REST Framework с аутентификацией по JWT.

## Назначение

YaMDb позволяет:
- **пользователям** — оставлять отзывы на произведения, ставить оценки от 1 до 10, писать комментарии к отзывам;
- **администраторам** — добавлять произведения, категории и жанры;
- **системе** — автоматически рассчитывать усреднённый рейтинг произведения из пользовательских оценок.

Произведения в сервисе не хранятся — YaMDb работает только с оценками и отзывами.

## Стек технологий

- Python 3.9+

- Sqlite
- JWT‑аутентификация (SimpleJWT)

### Как запустить проект:

Cоздать и активировать виртуальное окружение:

```
python -m venv env
```

```
source venv/Scripts/activate
```

Установить зависимости из файла requirements.txt:

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python manage.py migrate
```

Запустить проект:

```
python manage.py runserver
```
